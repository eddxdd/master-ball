# Frontend

React + TypeScript + Vite, shipped as a PWA. See [`Docs/frontend/README.md`](../Docs/frontend/README.md) for the folder structure/conventions, and [`Docs/setup.md`](../Docs/setup.md) for how to run the whole stack locally.

Quick reference (see `package.json` for the full list):

```bash
npm run dev         # start the Vite dev server
npm run lint        # Biome check
npm run typecheck   # tsc --noEmit
npm run test        # Vitest
```
